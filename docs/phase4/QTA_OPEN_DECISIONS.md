## Explicit non-inventions (hard guardrails)

- **No token ↔ credit conversion:** No conversion rate, exchange multiplier, or cross-unit arithmetic between tokens and credits is defined or implemented (`AGENTS.md`). Every QTA amount uses the single abstract label **`"đơn vị hạn mức"`** (`PD-Q1`).
- **No model pricing or financial billing:** Unit prices per model (`FRD §6 Should`) and vendor payment/cost calculation are **not** invented.
- **No consumption deductions:** Real AI invocation and consumption metering are out of scope (`FRD §1.3`); no consumption table or synthetic usage-subtraction rule is created in QTA. Entitlement responses return `actual_consumption: null`, `remaining_quota: null`, and `consumption_status: "NOT_INTEGRATED"`.
- **No non-monthly quota cycles:** Semester, Research Project, and Exam cycles are structurally excluded (`FR-QTA-010`, `FR-QTA-050`, `RULE-QTA-01`).
- **No client-trusted operator identity:** `suspended_by`, `restored_by`, `recorded_by`, and `audit_events.actor_id` come strictly from the server-authenticated session (`authority.actor_id`), never from `ordered_by` or any client request field.
- **No modifications to MDL:** `mdl/` code and migrations stay untouched (`PD-Q2`; one-way dependency `qta/` → `mdl/`).

## Project Owner decisions (`PD-Q1..PD-Q6`)

*Provenance for all six entries: **Project Owner decision, 2026-11-26** (not delegated).*

| ID | Topic | Decision (recorded verbatim) |
| --- | --- | --- |
| **PD-Q1** | Unit & allocation (`FR-QTA-011`) | Every QTA amount (school monthly total, group × model monthly limit) is one abstract unit, **"đơn vị hạn mức"**. It is never labelled tokens or credits; no price or conversion exists. `Allocated(month)` = sum of the base entitlement of every `ACTIVE` user across all models = sum over enrolled, active groups of (active members in `ACTIVE` state × sum of enabled per-model limits). Reducing the total below allocated → `409 QTA_BUDGET_BELOW_ALLOCATED` with `{allocated, deficit}`. CRT net grants will be added to allocated in Phase 5 through the same function. Directory growth and quota edits are never blocked; over-allocation is shown as a warning. Valid for this demo project; not an institutional accounting rule. |
| **PD-Q2** | Paid external model scope (`FR-QTA-040`) | `PAID_EXTERNAL_ONLY` = all models whose provider is `EXTERNAL`. Remove `mdl_models.billing_tier` and migration `0009` from every plan and document. |
| **PD-Q3** | Suspension duration & operator (`FR-QTA-040`) | Suspension `expires_at` is optional (`NULL` = until restored); if given it must be finite and in the future. No 365-day cap. `ordered_by` stays mandatory text; the operator always comes from the session. |
| **PD-Q4** | School monthly total decision date (`FR-QTA-010`) | `decision_date` is required together with `decision_number` for the school total. |
| **PD-Q5** | Mid-month change timing (`FR-QTA-021`, `FR-QTA-030`) | Mid-month membership/group/quota changes take effect immediately (`QD6`). |
| **PD-Q6** | Manual reset simulation month (`FR-QTA-032`) | Manual reset simulation is allowed for the **current month only** (`Asia/Ho_Chi_Minh`); never for a future month. |
